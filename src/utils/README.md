# Utils

- `logger.js` — pino
- `apiResponse.js` — `{ success, data | error }` envelope
- `AppError.js` — typed HTTP errors

- `money.js` — integer paise (Phase 2)
- `cache.js` — Redis get/set/delete (Phase 2)
- `crypto.js` — AES-256-GCM for bank account numbers (Phase 3)

`geo.js` and `time.js` are added in the phases that define discovery and IST business hours.
